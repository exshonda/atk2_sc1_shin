○概要

RH850/F1KM-S1ターゲット依存部(CCRH版)は，ルネサスエレクトロニクス社の
RH850/F1KM-S1 (R7F701684) を搭載したボードをサポートしている．

HSBRH850F1K用のターゲット依存部(hsbrh850f1k_ccrh / hsbrh850f1k_gcc)を
ベースに，F1KM-S1のクロック構成・ログ出力・ハードウェアカウンタに
合わせて作成した．CCRH用とGCC用を別ディレクトリに分けず，本ディレクトリ
だけで完結する構成としている．


○動作確認バージョン

 CC-RH V2.08.00

TOPPERS新世代カーネル用コンフィギュレータ(cfg)

 本リポジトリ同梱のPython版 (cfg/cfg_py/cfg.py)


○ビルド

Cygwin上のmakeでビルドする．CS+によるビルドはサポートしない．

    $ export PATH="/cygdrive/c/Program Files (x86)/Renesas Electronics/CS+/CC/CC-RH/V2.08.00/bin:$PATH"
    $ cd obj/obj_rh850f1kms1_ccrh
    $ make -j4

生成されるのは atk2-sc1.elf / atk2-sc1.srec / atk2-sc1.map である．
書き込みと実行はサポートしていない．


○ログ出力

ログ出力のため，RLIN32のポート2を使用する．

端子は次の通り．

・P10_14 : RLIN32TX (第2兼用)
・P10_13 : RLIN32RX (第2兼用)

データフォーマットは，

・115200bps、データ8bit、パリティなし、ストップ1bit、フロー制御なし

である．ボーレートレジスタの設定値はLINCLK(PCLK) = 40MHzを前提としている．


○クロック

・Main OSC   : 20MHz
・PLL1       : 120MHz (VCOOUT 480MHz / 4)
・CPUクロック : PLL1 (CPLL1OUT) 120MHz
・RLIN/TAUB  : PPLLCLK2 (40MHz)


○ハードウェアカウンタ

・サンプルプログラムにて，TAUB0のチャネル14, 15を使用．
・1個のカウンタに2つのタイマを使用している．
    差分タイマ：目的の時間を設定する時の現在時間(現在値タイマ)と次の満
    了時間との相対時間をカウントすることで目的の絶対時間に満了したこと
    とする.
        count mode:count down once
    現在値タイマ：カウンタ周期分のベースタイマを実現(絶対時間をカウント)
        count mode:continuous count down
・使用カウンタ情報
    カウンタ名：MAIN_HW_COUNTER
        差分タイマ  ：TAUB0 ch14
        現在値タイマ：TAUB0 ch15
        タイマクロック：625kHz (PCLK 40MHz の64分周)
        1ティック当たりの秒数：1.6us

・TAUBのチャネルデータ／カウンタレジスタは16bit幅である．このため
  OsCounterMaxAllowedValueは32000 (51.2ms相当)としている．
  他ターゲットと異なり約1秒周期のアラームは設定できないので，
  target_test.hのCOUNTER_MIN_CYCLEは約50msとしている．


○割込み要因番号

・RLIN32 RX : 166
・TAUB0 ch14 (差分タイマ)  : 156
・TAUB0 ch15 (現在値タイマ): 157


○メモリマップ

リンカ(rlink)の -start オプションでRAM先頭を 0xFEDE0000 としている．
別のRAM容量の品種を使用する場合はMakefile.targetを修正すること．
